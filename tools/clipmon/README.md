# clipmon (superseded)

Prefer **[`../anote-web`](../anote-web)** for Notes / Clip / Contacts via the encrypted repository.

If you still use clipmon:

```bash
cp tools/clipmon/local.example.json tools/clipmon/local.json
./tools/clipmon/run.sh
```

`local.json` is gitignored (WebDAV URL, username, password).
